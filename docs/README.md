# Docs

The written side of Fogwright, kept here so anyone with access to the repository can read and edit it.

| File | What it is |
| --- | --- |
| [lore.md](lore.md) | The world: the three ages, the gods, magic, the peoples, regions and cities, open questions |
| [design.md](design.md) | The game design document: pillars, systems, progression and the roadmap |
| [devlog.md](devlog.md) | The development log, newest entry first |
| [references/](references/README.md) | The turnaround sheets and screenshots, and a list of the outside inspiration |

These files are now the editable copies. They began as exports of the online docs on 23 November 2026; the three diagrams there (the timeline of the ages, the schematic world map and the roadmap) don't export to Markdown, so each one is marked by a note where it sits.

To edit: change the file on GitHub (the pencil icon) or in a clone, and commit. Plain Markdown: `#` headings, `**bold**`, `- ` lists, and `|` tables.
