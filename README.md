# Fogwright

A lightweight, cross-platform co-op MMO prototype: a high-fantasy world with steampunk-lite invention on its surface and a grimdark truth underneath. Browser-first (three.js), later wrapped for desktop and mobile. Built so most of the world is **generated by code rather than stored**: terrain, sky, water, vegetation, every building and street lamp, and soon the paint on every character.

## Run it

Serve the repository with any static file server and open `game/index.html`:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/game/index.html
```

`file://` won't work, because the character models are loaded over HTTP. On phones and tablets the game asks for landscape.

**Controls**
- **Classic (MMO):** tap or click a target, and your character auto-attacks. Skills are skillshots: drag to aim, release to cast.
- **Action (desktop):** WASD to move, 1–5 for skills aimed at the crosshair, left click to attack, right click to block.
- **Admin panel:** the Admin button, or `P` / `` ` `` on desktop. Teleports, time of day, invulnerability, fast travel speed and enemy spawning.

## What's in here

| Path | What it is |
| --- | --- |
| `game/index.html` | The playable prototype (v0.14), a single file. |
| `game/*.gltf.json` | The hero (Tinker) and the townsfolk (eight peoples). They're glTF with embedded buffers, saved as `.gltf.json` so any static host serves them. |
| `studies/peoples-viewer.html` | Lineup of the eight peoples and the city watch (first pass, kitbashed). |
| `studies/body-viewer.html` | The new direction: one seamless body with face and clothes painted by code, a head built from cross-sections (square jaw, real chin, heavy brow), and hair and beards as solid sculpted masses with painted strands, the way Valheim does them: short, swept, long, ponytail and topknot hair; short, full (spade), pointed, forked and braided beards; a moustache. A work in progress. |
| `studies/base-body-viewer.html` | **The current base body:** a Sketchfab model (see CREDITS.md) rigged to our skeleton and repainted by code, with our hair, beards, moustaches, Lean and Heavy builds, idle and walk. |
| `studies/female-body-viewer.html` | The female base body, built from scratch (`tools/blender/femalebody.py`): a sculpted frame and a cross-section head, rigged to the shared skeleton and painted by code. Work in progress. |
| `studies/tinker-viewer.html` | Review viewer for the Tinker hero model. |
| `tools/blender/` | Blender (bpy) scripts that build the characters. `tinker.py` makes the hero and the rig with its Idle, Walk and Aim animations; `races.py` makes the kitbashed peoples model; `body.py` makes the clean seamless base body; `kit.py` is the original building kit, now generated in code inside the game; `glb2json.py` turns a `.glb` into a `.gltf.json`. |
| `tools/test/smoke.js` | Headless smoke test: boots the game, visits a few places and reports page errors. |

### Rebuilding the characters

The scripts run with Blender's Python module (`bpy`, Blender 5.x), from `tools/blender/`:

```sh
python tinker.py -- tinker.glb   && python glb2json.py tinker.glb  ../../game/tinker.gltf.json
python races.py  -- peoples.glb  && python glb2json.py peoples.glb ../../game/peoples.gltf.json
python body.py   -- body.glb     && python glb2json.py body.glb    ../../studies/body.gltf.json
```

## Where things stand

- **World:** a Valheim-scale island with procedural terrain and biomes, plus authored places:
  - **The starting village.**
  - **Hollin's Cross:** the southern port.
  - **Aldrath's outer city:** the capital, roughly 600 m across. Its quarters each have a people's architecture; the rich live by the sealed core and the slums press against the castle walls. It has 450 Fog-pusher street lamps.
  - **The outskirts:** camps, stalls and trades kept outside the walls, with a gate checkpoint and guard patrols.
- **Sky:** a procedural sky with three moons, one of them broken.
- **Night:** the Fog strengthens; lanterns, street lamps and campfires push it back.
- **Core loop:** tab-target combat with skillshots or crosshair aiming, loot by rarity, and a starter quest chain.
- **In progress:** rebuilding characters the WoW way. One clean, seamless base body (male, then female), with faces and base clothing painted by code, plus a small library of shared garment meshes (coats, robes, helms, hair) that are retextured per people and armor tier.
