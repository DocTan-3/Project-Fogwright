# Quaternius Universal Base Characters (Standard, free)

CC0 1.0 (public domain) by Quaternius: https://quaternius.itch.io/universal-base-characters

- `Superhero_Male_FullBody.gltf`, `Superhero_Female_FullBody.gltf`: about 14,300 and 15,100 triangles, 65-bone rig (the same
  rig as the Universal Animation Library in assets/animations/quaternius, so those animations play on them directly).
- `hair/`: hairstyles and eyebrows rigged to the head bone: Buzzed, BuzzedFemale, SimpleParted, Long, Buns, Beard,
  Eyebrows_Regular, Eyebrows_Female (830-3,300 triangles). The hair's base colour is grey, meant to be tinted.

Textures are scaled from 2048 to 1024 px to keep the repository small; the full-size originals are in the download.
