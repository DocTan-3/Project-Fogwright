# Quaternius Universal Animation Library 1 and 2 (Standard, free)

CC0 1.0 (public domain) by Quaternius: https://quaternius.itch.io/universal-animation-library and
https://quaternius.itch.io/universal-animation-library-2. Animation viewer: https://quaternius.com/animviewer.html

- `UAL1_Standard.glb`, `UAL2_Standard.glb`: 43 animations each, in place (root motion disabled).
- `*_RM.glb`: the same with root motion baked in.
- `Mannequin_F.glb`: the female mannequin on the same rig.

Rig: 65 bones, Unreal-style names (root, pelvis, spine_01-03, neck_01, Head, clavicle/upperarm/lowerarm/hand with five-finger
chains, thigh/calf/foot/ball). Our MakeHuman bodies use a 19-bone rig, so these are retargeted (or the bodies re-rigged) in
the Godot move.
